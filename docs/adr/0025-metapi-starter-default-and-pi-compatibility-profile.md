# Make Meldra Starter the default and preserve Pi as an explicit Profile

The normal `metapi` command will start the reserved Meldra Starter Profile at `~/.metapi/profiles/default/`, so users immediately see Meldra's built-in Profile and workflow features. The reserved `pi` compatibility Profile will point directly to the original `~/.pi/agent` directory and is selected explicitly with `metapi --profile pi`; it preserves original Pi authentication, settings, sessions, packages, resources, and complete host-environment behavior. Unmatched directory resolution falls back to Meldra `default`, while original Pi compatibility remains available without copying or mutating its state.
