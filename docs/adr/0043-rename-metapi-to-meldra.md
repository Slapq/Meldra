# Adopt Meldra as the product brand

The product, primary CLI, UI, documentation, and release artifacts are renamed to Meldra to avoid conflict with an established AI project while retaining the existing M icon and a short, easy-to-type command. The primary command is `meldra`; `metapi` remains a compatibility alias, and established storage and protocol identifiers such as `~/.metapi`, `.pi/metapi.json`, `METAPI_*`, Profile Bundle metadata, Session entries, and `metapi/*` DSH RPC methods remain readable so existing installations, Profiles, Sessions, and external Runtimes continue to work.
