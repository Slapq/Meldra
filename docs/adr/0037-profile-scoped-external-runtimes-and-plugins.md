# Keep external agent runtimes and native plugins Profile-scoped

A DeepSeek Harness integration is an ordinary independent MetaPi Profile, not project configuration or a globally merged DSH environment. The Profile's portable manifest selects its Profile Runtime Provider and may declare provider-owned native plugins; import creates an isolated Profile and restores those declarations, while export records them without credentials, sessions, environment values, or package caches. Projects may recommend, bind, or select that Profile but cannot declare, install, merge, or override its Harness plugins. This replaces provider matching by reserved Profile name with explicit portable Profile composition and preserves Profile ownership across CLI, TUI, terminal commands, and deployment.
