# Official Pi Extension Examples

This is the complete catalog of the **78** entries under `packages/coding-agent/examples/extensions/` in the current Pi v0.84.2 baseline. They are loadable reference implementations, not default-enabled product plugins.

Category names come from `examples/extensions/README.md`. **Unlisted** means the entry exists in the official directory but is not present in that README's category tables.

## Catalog

### 1. `auto-commit-on-exit.ts`

- **Category:** Git Integration.
- **Surface:** no command or tool; handles `session_shutdown`.
- **Purpose:** reads the last assistant message, checks Git status, stages changes, and commits with text derived from that message.
- **State/dependencies:** changes the current Git worktree; calls `git status`, `git add -A`, and `git commit`.
- **Relations:** shares shutdown and Git process activity with other Git/session-lifecycle examples.
- **Evidence:** `auto-commit-on-exit.ts:8-44`; `README.md:95-98`.

### 2. `bash-spawn-hook.ts`

- **Category:** Unlisted.
- **Surface:** re-registers the built-in `bash` tool.
- **Purpose:** demonstrates `createBashTool(..., { spawnHook })` by sourcing `~/.profile` and adding `PI_SPAWN_HOOK=1` before execution.
- **State/dependencies:** no persistent state; delegates to Pi's Bash implementation.
- **Relations:** competes by name with every other `bash` override; it is an execution wrapper rather than a renderer.
- **Evidence:** `bash-spawn-hook.ts:11-29`.

### 3. `bookmark.ts`

- **Category:** Session Metadata.
- **Surface:** `/bookmark [label]`, `/unbookmark`.
- **Purpose:** assigns or removes labels on session entries for `/tree` navigation.
- **State/dependencies:** labels persist through Pi's session metadata APIs; no external dependency.
- **Relations:** complements `session-name.ts`; both use Pi-owned session metadata rather than separate files.
- **Evidence:** `bookmark.ts:11-49`; `README.md:123-126`.

### 4. `border-status-editor.ts`

- **Category:** Unlisted.
- **Surface:** automatic custom editor/footer; events `agent_start`, `agent_end`, `session_shutdown`, `session_start`.
- **Purpose:** puts work state, model, thinking, context, cwd, and Git branch into the editor border while hiding the standard working/footer presentation.
- **State/dependencies:** in-memory spinner/TUI/branch state; calls `git branch --show-current`.
- **Relations:** shares the single footer surface with `custom-footer` and the single editor surface with `modal-editor` and `rainbow-editor`.
- **Evidence:** `border-status-editor.ts:57-149`.

### 5. `built-in-tool-renderer.ts`

- **Category:** Custom Tools.
- **Surface:** re-registers `read`, `bash`, `edit`, and `write` with custom call/result renderers.
- **Purpose:** keeps the original executions while demonstrating compact presentation of built-in tools.
- **State/dependencies:** no persistence; delegates to Pi tool factories and uses Pi TUI components.
- **Relations:** competes by tool name with `minimal-mode`, backend replacements, and targeted wrappers.
- **Evidence:** `built-in-tool-renderer.ts:26-248`; `README.md:28-44`.

### 6. `claude-rules.ts`

- **Category:** System Prompt & Compaction.
- **Surface:** `session_start`, `before_agent_start`.
- **Purpose:** recursively finds project `.claude/rules/**/*.md` and appends an index telling the agent which rules can be read.
- **State/dependencies:** in-memory file list; reads the project filesystem.
- **Relations:** participates in the chained system prompt with `pirate`, `plan-mode`, `preset`, `prompt-customizer`, `ssh`, and others.
- **Evidence:** `claude-rules.ts:25-85`; `README.md:100-105`.
